
# NumPy Learning & Practice 🚀

Welcome to my NumPy learning repository!

This repository contains the programs and practice exercises I created while learning **NumPy** through the **Prime Batch course by Apna College**. The main goal of this repository is to understand NumPy fundamentals, practice array operations, and build a strong foundation in numerical computing with Python.

## 📚 Topics Covered

### 1. NumPy Arrays (ndarrays)
- Introduction to NumPy and its importance.
- Creating and working with NumPy `ndarray` objects.
- Understanding array dimensions, shapes, and data types.
- Performing basic operations on arrays.

### 2. Multidimensional Arrays
- Creating and working with 2D arrays.
- Creating and working with 3D arrays.
- Understanding the structure and dimensions of multidimensional arrays.
- Accessing and manipulating array elements.

### 3. Indexing and Slicing
- Accessing individual elements using indexing.
- Extracting specific elements from 1D, 2D, and 3D arrays.
- Slicing arrays to retrieve specific rows, columns, and sections.
- Selecting and manipulating array data efficiently.

### 4. Broadcasting
- Understanding the broadcasting mechanism in NumPy.
- Performing arithmetic operations on arrays with compatible shapes.
- Applying operations between arrays and scalar values.
- Learning how NumPy handles operations on arrays of different shapes.

### 5. Reshaping Arrays
- Changing the shape of arrays using `reshape()`.
- Understanding array shapes and dimensions.
- Converting arrays into different dimensional structures.
- Working with array size and shape compatibility.

### 6. Vectorization
- Understanding vectorized operations in NumPy.
- Performing element-wise calculations without explicit Python loops.
- Writing cleaner and more efficient numerical code.
- Understanding the benefits of vectorized operations.

### 7. Vector Normalization (Z-Score)
- Understanding standardization and z-score normalization.
- Calculating the mean and standard deviation of data.
- Transforming values based on their distance from the mean.
- Practicing data standardization using NumPy.

### 8. Important Mathematical Functions

#### Aggregate Functions
- `np.sum()`
- `np.mean()`
- `np.median()`
- `np.min()`
- `np.max()`
- `np.std()`
- `np.var()`

#### Rounding Functions
- `np.round()`
- `np.floor()`
- `np.ceil()`
- `np.trunc()`

#### Exponential Functions
- `np.exp()`
- `np.exp2()`
- `np.expm1()`

#### Logarithmic Functions
- `np.log()`
- `np.log2()`
- `np.log10()`
- `np.log1p()`

#### Other Useful NumPy Mathematical Functions
- `np.sqrt()` — Square root
- `np.square()` — Square of each element
- `np.abs()` — Absolute values
- `np.power()` — Element-wise powers
- `np.sin()` — Sine
- `np.cos()` — Cosine
- `np.tan()` — Tangent
- `np.add()` — Element-wise addition
- `np.subtract()` — Element-wise subtraction
- `np.multiply()` — Element-wise multiplication
- `np.divide()` — Element-wise division

These functions help perform mathematical calculations efficiently on individual values and entire arrays.
